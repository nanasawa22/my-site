**対象資料**

**分析日**: 2026-08-21
**目的**: セミナー「「AIが止まれば業務が止まる」時代へ」の構成に対する裏付けと補強材料の抽出

## 0. 結論

**このレポートは本セミナーにとって極めて価値が高い。理由は3つ。**

1. **第2章で定義した4つの非機能要件を、IDCの国内調査がほぼそのまま裏付けている。** 特に「コスト予測可能性」は、AIインフラサービスへの期待の**第1位**として調査結果に現れている。憶測ではなく国内実データで要件を立てられる。

2. **「推論が主戦場になる」というレポートの主題が、セミナーの主題と完全に一致する。** サブタイトルが「推論が主導する競争軸の転換」。本セミナーは「本番業務で使えるAI基盤」＝推論基盤の話であり、レポートはその市場的必然性を数値で示している。

3. **日本市場固有の論点「為替リスク」が発見された。** これは現構成にない視点であり、**コスト予測可能性の訴求を国内向けに大幅に強化できる**（→ 第3節）。

さらに、これまで信頼度Cの二次情報に頼っていた箇所を、**日本語の一次情報（IDC）に差し替えられる**。テンプレート規程2.5（出典は一次情報まで遡る）への適合という意味でも意義が大きい。

## 2. 本セミナーの4要件との答え合わせ

**ここが本分析の中核。** 第2章で定義した4つの非機能要件が、IDCの調査結果とどう対応するか。

| 本セミナーの要件 | IDCの調査結果による裏付け | 適合度 |
|---|---|---|
| **コスト予測可能性** | AIインフラの構築・運用・保守サービスへの期待、全体の**第1位が「AIインフラコストの可視化・最適化・予測可能性」** | ◎ 完全一致 |
| **可用性** | 期待の第2位が「マネージドサービスによる**安定したパフォーマンス**」。本格／高度活用セグメントでは特に「AIインフラの**安定運用**」への期待が高い | ◎ 完全一致 |
| **データ主権** | ソブリンAI推進目的の**第1位が「データ主権の確保」**。「自社の機密データが基盤モデルの学習に利用される可能性の技術的・法的な排除」も目的として明示 | ◎ 完全一致 |
| **移植性** | 本格／高度活用セグメントで「**プライベートAIインフラとパブリッククラウドの柔軟な組み合わせ**」「要件に合わせたAIインフラの柔軟な選択」の回答率が高い。ハイブリッド／マルチクラウドのAIインフラ設計・構築サービスの利用意向も高まる | ○ 実質一致（「移植性」という語ではなく「柔軟な組み合わせ／選択」として現れる） |

**評価：4要件はいずれも国内調査で裏付けられた。** 特筆すべきは、**AI活用が進んだ組織ほどこれらの要件を強く求める**という傾向がデータに現れている点。

> 「本格的／高度に活用のセグメントでは、マネージドサービスによる安定したパフォーマンス、プライベートAIインフラとパブリッククラウドの柔軟な組み合わせへの回答率が高い。AI活用の進展に伴って、複数のAIインフラの使い分けが進む中で、要件に合わせたAIインフラの柔軟な選択や、AIインフラの安定運用を望んでいる。」（p.52）

これは**セミナーの論旨そのもの**。「PoCの段階では見えないが、本番運用に入ると可用性・コスト・柔軟性が問題になる」という主張を、IDCが実データで裏付けている。第1章または第2章に1枚追加する価値がある。

## 3. 🔴 最重要の発見 — 「為替リスク」という日本固有の論点

**現構成に欠けていた視点。** ソブリンAIの推進目的として、IDCは以下を挙げている（重視される順）：

1. データ主権の確保
2. **為替リスクの回避**
3. 地政学リスクへの対応
4. 知財／機密情報の保護

レポートの記述（p.33）：

> 「データを外国政府の管轄下に置くリスクの回避、**急激な為替変動によるサービス利用料などの急騰への対応**、国際情勢の変化によるサービス停止や技術提供の制限、自社の機密データが基盤モデルの学習に利用される可能性の技術的・法的な排除などが目的となっている。」

### なぜこれが重要か

海外LLMプロバイダの利用料は**ドル建て**である。つまり国内企業にとってAI利用コストは、

- トークン消費量が実行時に決まる（**量の不確実性**）
- 単価が為替で変動する（**価格の不確実性**）

という**二重の不確実性**にさらされている。現構成の第2章スライド9は前者しか扱っていない。

### 産業分野別の傾向（そのまま業種別の刺さり方の地図になる）

| 産業分野 | 最も重視する目的 |
|---|---|
| 製造 | データ主権、地政学リスクへの対応 |
| **金融** | **為替リスクの回避**、地政学リスクへの対応 |
| 流通／サービス | データ主権の確保、為替リスクの回避 |
| 通信／情報サービス | データ主権の確保（最重視） |
| 組立製造・通信／情報サービス | 自社独自のAIによる競争優位を特に重視 |
| 政府／公共（参考値） | データ主権、地政学リスク、日本固有のコンテキスト対応 |

**金融と流通／サービスに対しては、為替が第一級の訴求軸になる。** 聴衆の業種構成が分かっている場合、この表で語り分けができる。

## 4. 推論こそオンプレという裏付け

セミナーがセルフホスト推論の価値を語るうえで、決定的なデータ。

### メインの実行環境（現在）

| | パブリッククラウド系（SaaS＋IaaS/PaaS） | プライベートAI環境 |
|---|---|---|
| 学習 | 60%超 | 20%強 |
| **推論** | 40%超 | **40%強** |

**推論では、プライベートAI環境がすでにパブリッククラウドと拮抗している。** 学習とは明確に異なる。

### 3年後の想定

- **学習**：パブリッククラウドIaaS/PaaSに加え、プライベートAI環境の割合が30%強に高まる
- **推論**：自社所有のプライベートクラウド、**自社所有のオンプレミス環境（非クラウド）**、加えて**エッジ／オンデバイス実行**（店舗端末、PC、工場内）の割合が高まる

### AIインフラの利用予定（ITインフラ意思決定者 n=551）

| 配備形態 | 学習 | 推論 |
|---|---|---|
| パブリッククラウド（IaaS） | 50%超 | 50%超 |
| 専有型ITインフラ（オンプレ／プライベートクラウド／ホステッド） | 45%強 | 35%弱 |
| エッジ | 20%強 | 20%強 |

> **読み方の注意**: 複数回答である。「パブリッククラウドが50%超」と「専有型が35〜45%」は排他ではなく、**多くの組織が両方を使う**ことを示している。これはまさに「単一APIで両方を束ねる」という統合エンドポイントの価値そのもの。**この読み解きはスライドで明示する価値がある。**

### 組織内データのAI活用状況

| 段階 | 割合 |
|---|---|
| 未活用 | 10%強 |
| 検証のみで活用 | 20%弱 |
| **（小計）本格活用に至っていない** | **30%強** |
| 部分的に活用 | 40%超 |
| 本格的に活用＋高度に活用 | 20%強 |

IDCの評価は「現段階では、アーリーアダプターが機密情報や個人情報を含む組織内データのAI活用に取り組み始めている状況」。

**セミナーでの使い方**: 「本格活用は20%強。つまり今から基盤を設計すれば先行者になれる」という前向きな文脈でも、「まだ2割しかいないからこそ、先行事例の設計論が価値を持つ」という文脈でも使える。

## 5. 構成への反映提案

優先度順。

### 提案① 第2章スライド9（コスト予測可能性）に「為替」を追加 ★最優先

現在は「消費量が実行時に決まる」という**量の不確実性**のみ。ここに**価格の不確実性（為替）**を足して二重構造として提示する。

```
現行 → エージェントの消費量は実行時に決まる
改訂 → コストの不確実性は二重である
        ① 量 — トークン消費量が実行時に決まる
        ② 価格 — ドル建て課金が為替で変動する
        出典：IDC #JPJ54233926（ソブリンAI推進目的の第2位が「為替リスクの回避」）
```

セルフホスト推論の動機として、日本の聴衆に最も具体的に響く論点。

### 提案② 第1章に「市場の転換点」スライドを追加 ★推奨

**2027年に推論が学習を上回る**という予測は、セミナーの前提を市場データで裏付ける。第1章スライド3（依存構造の変化）の直後、または置き換えとして。

```
学習向け  CAGR  0.3%（2026年ピーク、以降横ばい〜微減）
推論向け  CAGR 13.6%（2030年に5,528億円）
2027年、推論が学習を上回る
→ 「作る」から「使い続ける」フェーズへ。止まらないことが前提条件になる
出典：IDC #JPJ54233926
```

現行のGartner（40%がAIエージェント搭載）と併用してもよいが、**国内データのほうが日本の聴衆には効く**。差し替えも選択肢。

### 提案③ 第2章の冒頭で「4要件はIDC調査と一致する」ことを示す ★推奨

第2章スライド7（4つの非機能要件）に、IDC調査の裏付けを併記する。これで4要件が「登壇者の私見」ではなく「国内調査に基づく整理」になる。訴求力が大きく変わる。

### 提案④ 第5章スライド24（単一API）に複数回答の読み解きを追加

「パブリッククラウド50%超・専有型35〜45%（複数回答）」＝**多くの組織が両方を使う**。統合エンドポイントの価値を、市場データから直接導ける。

### 提案⑤ 業種別の訴求軸を口頭で使い分ける

聴衆の業種構成が事前に分かる場合、第2章スライド9（データ主権）で第3節の表を使って語り分ける。スライドに載せず、口頭の引き出しとして持つのが現実的。

### 提案⑥ 阻害要因は「あえて触れない」判断もある

メモリー需給逼迫、DC キャパシティ不足は、**セルフホスト推論の導入障壁**として機能する。セミナーの訴求と逆方向に働くため、質疑で問われた場合に備えるに留め、スライドには載せない判断が妥当。ただし**触れられた場合に誠実に答えられる準備は必要**。

## 7. このレポートで解決しなかった論点

セミナーの主張のうち、本レポートでは裏付けが得られなかったもの。別途一次情報の確保が必要。

- **エージェントのトークン消費量が通常のチャットボットの数十〜数百倍である**という主張 — 本レポートはインフラ市場が対象であり、トークン単位の消費特性は扱っていない
- **LLMプロバイダの障害・SLA水準** — 同上。現行のAzure status history 等の引用を継続する
- **AI Gateway / Agent Gateway という製品カテゴリの市場動向** — 本レポートはサーバー／ストレージとインフラサービスが対象で、ゲートウェイ層のソフトウェアは範囲外

## 8. ベンダー動向（参考）

セミナー本編では使わないが、文脈把握のため。

- 国内AIインフラ市場シェア 2025年上半期：**1位 NVIDIA**、2位 Supermicro、3位 デル・テクノロジーズ
- 2023年以降、政府の助成金を受けた国内サービスプロバイダー向け大型案件がシェアを大きく左右
- 主要ベンダーとして CTC、デル、富士通、日立ヴァンタラ、日本HP、NEC、NTTデータ、NTTPC、NVIDIA、Supermicro を分析。**Nutanix は個別の分析対象に含まれていない**（本レポートはサーバー／ストレージのハードウェア市場が主対象のため）
- 2030年は国家プロジェクト**富岳NEXT**の稼働開始が市場成長を押し上げる見込み

### IDCのITサプライヤー向け提言（3点）

1. エンタープライズ向けの包括的なAIインフラソリューションを整備すべき — 競争の焦点は「GPUサーバーの供給規模」から「エンタープライズにおける実装を支える総合的な能力」へ移行する
2. エンタープライズ領域を見据えたAIインフラエコシステムを構築すべき
3. AIの本番実装に向けたAIインフラの支援能力を強化すべき — **「既存ITインフラの延長としてAIインフラを追加する発想から脱却し、AI活用を前提とした全社的なAIインフラ再構築への視座の転換を促すべき」**

> 3点目の「既存ITインフラの延長という発想からの脱却」は、**セミナー第3章の主張（アプリ個別実装からの脱却、横断レイヤへの責務分離）と同じ構造**。第4章の「API Gatewayとの構造的相似」を補強する材料として、口頭で引用できる。
